## Plan

1. Phase 0 (done): shared contract `../assets/ASSET_SPEC.md`; shared helper `../scripts/assets/_common/common.py` (tested with a self-test asset); folder layout `../assets/components/<cat>/`, `../scripts/assets/<cat>/`, `v1/DevLog-003-<cat>.md`.
2. Phase 1: category agents build assets in parallel (below). Each agent owns its category folder, build scripts and devlog; none edits shared files or the storyboard scripts.
3. Phase 2: coordinator assembles v1.0 (`../scripts/build_film_v1.py`, `../scenes/film_v1_0.blend`) by appending assets into the storyboard timeline (same scene timing, cameras and captions as v0.2), renders `../outputs/film_v1_0_<date>.mp4`.
4. Phase 3: fresh-context audit agents check accuracy (dimensions vs sources, missing items vs storyboard) and the rendered film; corrections recorded here.
5. Phase 4: Wentao reviews modeling details; feedback becomes v1.1.

- Caption/label overlay system, image-sequence generators (`tex_gen.py`) and the camera/timeline code carry over unchanged from v0.2.
