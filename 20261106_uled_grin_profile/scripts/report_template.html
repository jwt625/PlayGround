Method, assumptions, validation

Objective

Minimize the overfilled-launch (OFL) RMS intermodal group-delay spread, equal power in every guided scalar LP mode (degeneracy 1 for \(l=0\), 2 for \(l>0\)), averaged over the source spectrum \(S(\lambda)\) (Gauss-Hermite nodes):

\[ \sigma_\text{modal}^2 = \sum_j S_j\, \frac{\sum_m w_m (\tau_m(\lambda_j) - \bar\tau(\lambda_j))^2}{\sum_m w_m}. \]

Robust objective: \(\sigma_\text{rob} = \sqrt{\langle \sigma_\text{modal}^2 \rangle}\) over the ensemble \(x_0 \times \{0.98, 1, 1.02\}\) (all sources) and \(\lambda_0 + \{-10, 0, 10\}\) nm (uVCSEL).

Mode solver

Scalar weakly guiding equation per azimuthal order \(l\), cell-centered radial finite differences, Dirichlet at \(r = a + 15\) um, symmetric tridiagonal eigenproblem (LAPACK stemr), guided modes \(\beta > k n_\text{clad}\):

\[ \psi'' + \tfrac{1}{r}\psi' - \tfrac{l^2}{r^2}\psi + k^2 n^2(r,\lambda)\,\psi = \beta^2 \psi. \]

Group delay per mode (Hellmann-Feynman, exact for the discrete problem), with the local material group index \(N = n - \lambda\, dn/d\lambda\):

\[ \frac{\tau_m}{L} = \frac{1}{c}\frac{d\beta}{dk} = \frac{k}{c\,\beta}\,\frac{\langle\psi| n N |\psi\rangle}{\langle\psi|\psi\rangle}. \]

Material

Three-term Sellmeier, SiO2 (Malitson 1965) and GeO2 (Fleming 1984); binary glass coefficients \(B_i, \lambda_i\) linear in GeO2 mole fraction \(x\). Cladding pure SiO2. Peak \(x_0\) set by the NA at the source center wavelength.

Profiles (monotonic, axially symmetric)

\(x(r) = x_0\,[1 - F(r/a)]\), \(x = 0\) for \(r \ge a\). Alpha: \(F = \rho^\alpha\). Bernstein: \(F = \sum_k c_k B_{k,8}(\rho)\), \(0 = c_0 \le \dots \le c_8\), \(c_8 = 1\) (continuous) or \(c_8 < 1\) (edge step). Staircase: \(N\) layers with free radii and levels, first level \(x_0\).

Coupling floor

Fixed core and peak NA do not fix coupling (a pilot collapsed to about one guided mode). Free-form and staircase designs keep fiber etendue \(G = \int \pi (n^2 - n_\text{clad}^2)\, 2\pi r\, dr\) (proportional to guided mode count) at least \(0.99\times\) that of the alpha optimum of the same case; penalty 100 ps/m per unit shortfall.

Optimizer

Per design 3 starts (seed 1 at the alpha optimum, others perturbed); each runs CMA-ES, then Powell, then Nelder-Mead. Shaded bands in the layer plot span the seeds.

Bandwidth

First \(|H(f)| = 0.5\) of the pooled impulse response (modal only at \(\lambda_0\), or modal + chromatic over the spectrum), scaled to \(L\).
