# SPEC proposals from batch p1_01 (not applied)

## deng2026 (sims/deng2026/config.yaml)
- Undisclosed dielectric constants. The paper states no RF permittivity for BTO, LSAT or Si3N4 and no Si3N4 refractive index. The engine (correctly) rejects a dielectric without `eps_r`, so the config is a geometry-and-provenance record that cannot run. Proposal: allow `eps_r: {unknown: true}` (or a top-level `status: incomplete`) so the app can load and draw the geometry, list the blockers from `missing`, and refuse only the solve. Until decided, the values are left out and listed under `missing`.
- Ferroelectric crystal notation. BTO (001) film with the electrode field along the in-plane [110] direction needs the r42 contraction rotated 45 degrees about the film normal. `crystal: {cut, propagation}` with axis names cannot say [1-10]/[110]; the config uses `propagation: "[1-10]"` as a free string and `eo_axis: auto` cannot resolve it. Proposal: `crystal: {cut: z, field_dir: [1,1,0], propagation_dir: [1,-1,0]}` with Miller-direction vectors in the crystal frame, plus a tetragonal (4mm) tensor preset.
- Single-arm drive. Vpi*L 0.7 V*cm refers to one RF-driven arm of an MZI whose other arm only carries DC tuning. SPEC states the optical arm/push-pull factor is not defined; `line.differential: false` records the drive but not the factor. Proposal: a `line.drive` block `{arms_driven: 1, arm_polarity: single}` consumed by the EO overlap stage.
- GSG line where only one gap holds a waveguide. The config models one G-S gap and drops the second ground; a `line.topology: gsg_one_gap` hint (second ground gap width as an input) would let the electrostatics add the far ground.
- Material table with a conductor and an `unknown` dielectric in the same file; no change needed beyond the first bullet.
