# SPEC proposals from batch p1_02 (not applied)

## he2019 (sims/he2019/config.yaml)
- Undisclosed dielectric constants (same issue as p1_01 deng2026). The paper gives no refractive index, RF permittivity or Pockels coefficient for LN, BCB, SiO2 or Si, and no gold conductivity. The values are omitted and listed under `missing`; nothing was filled from memory. The engine rejects a dielectric without `eps_r`, so the config is a geometry-and-provenance record only. Proposal (repeats p1_01): allow `eps_r: {unknown: true}` or a top-level `status: incomplete` so the app can draw the geometry and refuse only the solve; a project-level sourced-constants table (with citation and a verified flag) that configs can reference would let reviewers fill constants once for all LN papers.
- Provenance class for unverified standard values. `standard_reference` requires a citation checked against the source; there is no class for "recalled, not verified". None was used here, but a class such as `standard_unverified` (rendered as a warning in the app) would let a later pass add constants without overclaiming.
- Optional layer presence. Fig. 1(b) draws small Si rectangles under each LN rib (inverse-taper tips of the vertical adiabatic couplers); the text does not say whether they are present in the phase-shifter section. Proposal: a region flag `presence: uncertain` that the app can toggle, instead of omitting the region and listing it only in `missing`.
- Device variants sharing one cross-section (he2019-a 3 mm, he2019-b 5 mm). Same gap as chen2022: no variants mechanism; the config carries the 3 mm device and says so. Proposal: `variants: [{device_id, line: {length_mm}, targets: [...]}]` overriding line length and target sources.
- Push-pull factor with one waveguide per gap. Vpi and VpiL (7.4 V, 2.2 V*cm) are MZM-level push-pull values and the geometry realizes push-pull through the two gaps; SPEC still leaves the optical arm/push-pull factor undefined for the EO overlap stage. Proposal: `line.drive: {arms_driven: 2, arm_polarity: opposite}` consumed by the EO overlap stage.
